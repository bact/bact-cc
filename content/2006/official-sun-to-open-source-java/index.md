[“ Yes, we really are going to open-source the JDK ”](http://blogs.sun.com/roller/page/mr?entry=yes_we_really_are_going)

คราวนี้ของจริง ประกาศเองเลย ไม่ใช่ข่าวลือ พร้อมกำหนดเดือนเรียบร้อย  
สัญญาอนุญาตยังไม่ประกาศว่าจะเอาแบบไหน แต่เป็น OSI-approved แน่  
(และถ้าเกิดสงสัย, สัญญาแบบ [CDDL](http://www.sun.com/cddl/) ก็**เป็น OSI-approved** — [วิกิพีเดีย](http://en.wikipedia.org/wiki/CDDL): “The CDDL is one of the 9 preferred licenses listed by the OSI.”)

Hotspot VM (เวอร์ชวลแมชชีน/รันไทม์) กับ javac (คอมไพเลอร์) [จะเปิดเดือนตุลาคมนี้](http://www.vnunet.com/vnunet/news/2162306/first-open-source-java-promised) ส่วนที่เหลือจะตามมาต้น ๆ ปีหน้า

ข้างบนนั่นคือ Java SE แต่ไม่ได้มีแค่นั้น [ยังมี Java ME ด้วย](http://www.eweek.com/article2/0,1895,2003567,00.asp) ภายในปลายปีนี้  
(ส่วน Java EE นั้นเปิดโค้ดไปนานแล้ว ในชื่อ [GlassFish](https://glassfish.dev.java.net/) ใช้สัญญา CDDL)

จากข่าวนั้น จะมีบางส่วนของโค้ด Java SE ที่ไม่ได้เปิด เนื่องจากไม่ใช่สิทธิของซัน เช่นโค้ดเกี่ยวกับ [Font Rasterizer](http://java.sun.com/j2se/1.4.2/docs/guide/2d/new_features.html#FH) โดยจะแจกจ่ายในรูปไบนารีแทน และสามารถใช้ build ตัว Java SE ได้แน่นอน

ติดตามข่าวคราวความเคลื่อนไหวได้จากเว็บไซต์เฉพาะที่เพิ่งเปิดใหม่  
[Open Sourcing the JDK](http://community.java.net/jdk/opensource/) — a community site for open sourcing Sun Java implementation
