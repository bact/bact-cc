“ ผมกลัวจะเชื่อในสิ่งที่เห็น
ขอคุณโปรดกลัวที่จะเชื่อในสิ่งที่จะได้อ่าน ”

หมายเหตุ: มีข้อมูลบางส่วนถูกปรับปรุงตามข้อมูลที่ได้รับเพิ่ม ดูตรงส่วนที่มีเขียนว่า “update: 10 ต.ค. 2549“

สืบเนื่องจาก ICT Block web มั่ว – กรณีมหาวิทยาลัยเที่ยงคืน (6 ต.ค. 2549) คุณ Conductor ได้ตั้งข้อสังเกตว่า ในบางกรณีที่เราเข้าเว็บบางแห่งไม่ได้ และคิดว่ามีการบล็อกเว็บนั้น จริง ๆ แล้วอาจจะเป็นเพราะเหตุทางเทคนิคก็ได้ คือไม่ได้มีใครไปบล็อกเว็บนั้นแต่อย่างใด เราอาจจะเข้าใจผิด ควรจะตรวจสอบให้ดีเสียก่อน และใน อีกมุมมองกรณีมหาวิทยาลัยเที่ยงคืน (6 ต.ค. 2549) คุณ mk ก็สรุปให้ว่า คุณ Conductor เห็นว่า เว็บม.เที่ยงคืน อาจจะถูกขโมยโดเมน (hijack domain) ไป

พูดสั้น ๆ ตรงนี้ก็คือ
อย่าเอะอะเหมาว่า อะไร ๆ ก็คือการบล็อก
ตรวจสอบให้ดีก่อน

กรณีของม.เที่ยงคืน ในขณะนี้นั้น ผมไม่แน่ใจว่ามี/ยังมีการบล็อกอยู่รึเปล่า
(คือ อาจจะไม่เคยถูกบล็อกเลย หรือเคยถูกบล็อกแต่ตอนนี้เลิกบล็อกแล้ว หรือว่ายังถูกบล็อกอยู่)

เนื่องจากตอนนี้ (9 ต.ค.) ผมทดลอง (ผ่าน ISP เมืองไทยแห่งหนึ่ง) เข้าเว็บม.เที่ยงคืน
ปรากฏว่า เข้าได้เกือบทุกหน้า – ยกเว้นหน้าแรก

update: 10 ต.ค. 2549 จากข่าว
ตอนนี้ (10 ต.ค.) แน่ชัดแล้วว่า เว็บม.เที่ยงคืนเคยถูกบล็อก (โดยเป็นการบล็อก IP เลย) แต่ในปัจจุบันไม่ได้ถูกบล็อกแล้ว

แม้จะเข้าได้ (ไม่มีข้อความแสดงความผิดพลาด)
กลับแสดงแค่หน้าขาวว่าง ๆ มีเพียงคำว่า www.midnightuniv.org เท่านั้น

จากการทดลองนี้ ผมจึงมีข้อสังเกต (เพิ่มเติมจากคุณ Conductor) ดังนี้:

คิดว่า อาจจจะเป็นกรณีใดกรณีหนึ่ง ดังต่อไปนี้:

  1. กรณีการถูกขโมยโดเมน (hijack domain) ไป แล้วปรับเปลี่ยนหน้าแรกเป็นอย่างอื่น (เช่น ทำให้ว่าง) ในขณะนี้ (9 ต.ค.) น่าจะไม่ใช่แล้ว เพราะการ redirect หรือชี้ไปยังเว็บอื่น ก็น่าจะเป็นหมดทุกหน้า ทุก url ที่อยู่ในโดเมนเดียวกัน ไม่ใช่เป็นเฉพาะหน้าใดหน้าหนึ่ง
    (เว้นเสียแต่ว่าคุณขโมย จะขยันจัด ก็อปปี้ทั้งเว็บไปด้วย แล้วเปลี่ยนแค่บางหน้า)
    อย่างไรก็ตาม ก่อนหน้านี้ อาจจะมีการขโมยโดเมนเกิดขึ้นจริงก็ได้
  2. ยังเป็นไปได้ว่า ทางเว็บม.เที่ยงคืน อาจจะ “พัก” หน้าแรกไว้ด้วยตัวเอง เพื่อรอจนกระทั่งการย้ายเซิร์ฟเวอร์เสร็จสิ้นก่อน — update: 10 ต.ค. 2549 จากข่าว (ย่อหน้า 5) ม.เที่ยงคืนเป็นผู้ “พัก” หน้าแรกด้วยตนเองจริง: “แม้หลังจากที่มีการคลายบล็อคแล้ว แต่มหาวิทยาลัยเที่ยงคืน ยังคงไม่เปิดทำการเว็บไซต์ของตนเอง เพราะหากเราใช้พื้นที่เก่าที่เรามีสิทธิ์จะใช้โดยเสรี ก็อาจถูกบล็อคโดยกระทรวงหรือโดยเจ้าหน้าที่กระทรวงฯ ซึ่งทำโดยพลการอีก อันจะเป็นเหตุให้บริษัท Thaiis.com ได้รับความเดือดร้อนไปด้วย”
  3. ที่น่าจะสบายใจได้อย่างหนึ่งก็คือ ตัวเนื้อหานอกจากหน้าแรก ยังอยู่ในสภาพเดิม ยังไม่หายไปไหน และยังเรียกดูได้
  4. ส่วนกรณีการถูกบล็อกนั้น ก็ยังตัดทิ้งไปไม่ได้เสียทีเดียว เพราะการบล็ิอกเฉพาะหน้านั้น ก็เป็นไปได้เช่นเดียวกัน — update: 10 ต.ค. 2549 สถานการณ์ปัจจุบันนั้น ไม่ใช่การบล็อกแล้ว แต่มีการบล็อกเกิดขึ้นก่อนหน้านี้จริง เป็นการบล็อกทั้ง IP เลย ดูข่าว (ย่อหน้าแรก)

ทั้งหมดนี้เป็นการสรุปจากการสังเกตด้วยเว็บเบราเซอร์เท่านั้น ไม่ได้ใช้ซอฟต์แวร์ตรวจสอบเครือข่ายอื่นใด
สำหรับการวิเคราะห์ที่ละเอียดกว่านี้ และความเป็นไปได้อื่น ๆ ซึ่งบางอันใช้ข้อมูลจากเครือข่ายประกอบ (traceroute, ICMP, IP, etc.)
ให้ดูต่อที่ความเห็นของคุณ Conductor

ผมก็คิดว่ามันเป็นไปได้ … แต่ก็ควรจะใช้ความระมัดระวังเช่นเดียวกัน ก่อนจะสรุปเช่นนั้น

ทำไมถึงคิดอย่างนั้น ?

ถ้าดูกรณีของเว็บ Tor ประกอบ
จะเห็นว่าเราเข้าเว็บ Tor ที่ http://tor.eff.org/ ไม่ได้
โดยจะมีข้อความบอกความผิดพลาดว่า:

Not Found
The requested URL /favicon.ico was not found on this server.

Additionally, a 404 Not Found error was encountered while trying to use an ErrorDocument to handle the request.

(ถ้าคุณใช้ Internet Explorer คุณอาจะเห็นข้อความต่างไปจากนี้ แต่นั่นไม่ใช่ประเด็นสำคัญ ลองอ่านต่อไป คุณจะพบวิธีอื่นที่คุณสามารถทดลองกับ Internet Explorer ด้วยตัวคุณเองได้)

ซึ่งดูเหมือนไม่ได้ถูกบล็อกแต่อย่างใด
แต่เหมือนกับว่า ทางเว็บ Tor มีปัญหาเอง
(จากข้อความนั้น จะบอกว่าหาไฟล์ ที่ [http://tor.eff.org]/favicon.ico ไม่เจอ และนอกจากนั้น ยังมีมีความผิดพลาดชนิด 404 Not Found เกิดขึ้นอีกด้วย เนื่องจากการเรียกใช้ ErrorDocument อะไรซักอย่าง)

แต่เมื่อเราลองเข้าเว็บ http://tor.eff.org/ ด้วย open proxy
(เช่นด้วย Torpark หรือ UltraSurf หรือเซ็ตให้เบราเซอร์ใช้ open proxy — ดูวิธีใช้ Torpark (ภาษาไทย) ได้ที่ http://wonam.exteen.com/20060923/tor )
จะพบว่าเข้าเว็บได้ตามปกติ ไม่มีข้อความแสดงความผิดพลาดใด ๆ ทั้งสิ้น

… มีอะไรเกิดขึ้น ?

“ ข้อความลวง ? ” (ว่ามันเป็นความผิดพลาดทางเทคนิค ?)

ผมข้อสังเกตคือ
ก่อนทดลองเข้าเว็บ http://tor.eff.org/ นั้น
ผมได้ลองล้างแคชออกหมดแล้ว เพื่อความแน่ใจ ว่าจะไม่มีอะไรค้างอยู่
ปรากฎว่าในหน้าที่แสดงข้อความว่า
“ The requested URL /favicon.ico was not found on this server. ”
(ไม่พบ URL /favicon.ico ที่ร้องขอ บนเซิร์ฟเวอร์นี้.)
นั้น ตรงข้างซ้ายของ url, ที่ address bar, กลับมี favicon ปรากฏอยู่อย่างหน้าตาเฉย
(ทดสอบด้วย Firefox ถ้าใช้ Internet Explorer อาจได้ผลแตกต่างไป)
… ซึ่งขัดกับข้อความแสดงความผิดพลาดที่ปรากฏอย่างมาก
(ข้อมูลเทคนิค: ไฟล์ favicon.ico ที่ข้อความข้างบนบอกว่าหาไม่เจอนั้น
เป็นไฟล์ที่เก็บรูปไอคอนเล็ก ๆ สำหรับแทนเว็บไซต์ หรือที่เรียกว่า “fav icon” หรือ favorite icon)

และเมื่อผมลองพิมพ์ http://tor.eff.org/favicon.ico ที่ address bar แล้วกด Enter
เพื่อดูว่า ไฟล์ไอคอนนี้ หาไม่เจอจริงหรือ ?
เบราเซอร์ผมก็แสดง favicon ของ Tor ออกมาได้ (รูปหัวหอม)

เอ๊ะ!? .. ไหนว่าหาไม่เจอไง?

และโดยปกติแล้ว แม้เบราเซอร์จะหา favicon ไม่เจอจริง ๆ
มันก็ไม่น่าจะมีผลต่อการแสดงหน้าเว็บไม่ใช่หรือ ?
(ก็แค่ไม่แสดง favicon เท่านั้น แต่ยังแสดงหน้าเว็บอยู่)

update: 10 ต.ค. 2549 ทดลองเข้าเว็บโป๊ www s-cute com ได้ผลลัพธ์แบบเดียวกันเป๊ะ: หา favicon.ico ไม่เจอ แต่แสดง favicon ที่ address bar ได้!

อ้อ เรายังมีเรื่อง 404 Not Found นี่ … และ ErrorDocument อะไรซักอย่าง
ปัญหามันอาจจะอยู่ตรงนี้ก็ได้ มันอาจจะเป็นปัญหาเทคนิคจริง ๆ

404 Not Found ? … ตรงนี้ก็น่าสนใจ
เนื่องจาก ลักษณะข้อความบอกความผิดพลาด (error message) นั้น ผิดปกติ และดูเหมือนถูกเปลี่ยนแปลง

โดยผมได้ทดลองเข้า url มั่ว ๆ อันนี้
http://tor.eff.org/youdonthavethisblabla.html
(ซึ่งผมคิดว่ายังไงมันต้องเข้าไม่ได้แน่ ๆ ล่ะ เพราะมันไม่มี บล็อกหรือไม่บล็อก มันก็เหมือนกัน เพราะมันไม่มี .. ต้องได้ 404 Not Found ชัวร์ ๆ)
ทั้งแบบผ่านและไม่ผ่าน open proxy

ปรากฏว่า ถ้าเกิดผมเปิดโดยไม่ผ่าน open proxy ผมก็จะได้ข้อความแสดงความผิดพลาดเหมือนเดิม (พูดถึง /favicon.ico และ ErrorDocument) คือ:

Not Found

The requested URL /favicon.ico was not found on this server.

Additionally, a 404 Not Found error was encountered while trying to use an ErrorDocument to handle the request.

แต่ถ้าเปิดผ่าน open proxy ผมกลับได้ข้อความแสดงความผิดพลาดอีกแบบ (พูดถึงไฟล์ที่ผมถามถึง) คือ:

Not Found

The requested URL /youdonthavethisblabla.html was not found on this server.
—
Apache Server at tor.eff.org Port 80

ไม่เหมือนกัน!

เอาล่ะ ลองนึกปัญหาทางเทคนิคอะไรก็ได้หน่อย ที่ทำให้ข้อความมันออกมาไม่เหมือนกัน ?

ก็ถ้ามันเรียกหา url เดียวกัน แล้วมันจะมีความผิดพลาดที่ต่างกันได้ยังไง ?
… เว้นเสียแต่ว่าจะมีอะไรมีกั้นตรงกลาง เปลี่ยนแปลงอะไรบางอย่าง ?

หรือไม่มี ?

ใครมีคำอธิบายบ้างครับ ?

มีโอกาสบ้างไหม ที่เราถูกทำให้เข้าใจผิดได้ว่า นี่ (กรณีเช่น Tor) คือปัญหาทางเทคนิคของเว็บไซต์เอง ไม่ได้เกี่ยวกับการบล็อก

ดูประกอบ:

  • แถลงการณ์คัดค้านการปิดช่องทางการสื่อสารเสรี
  • ICT Block web มั่ว – กรณีมหาวิทยาลัยเที่ยงคืน, อีกมุมมองกรณีมหาวิทยาลัยเที่ยงคืน
  • จดหมายเปิดผนึกถึงประชาชน นักวิชาการและเพื่อนสื่อมวลชน: การต่อสู้เพื่อให้ความจริงพูดได้

ดูเพิ่ม: วิธีการใช้งาน Tor – เพื่อเสรีภาพในการเข้าถึงข้อมูล (และเสรีภาพในการรับรู้ว่า เรากำลังถูกกันให้เข้าถึงข้อมูลอะไรไม่ได้บ้าง) (pdf)

สรุปความเห็นผม:

  • ผมว่าตอนนี้เว็บม.เที่ยงคืนเค้ากำลังย้ายเซิร์ฟเวอร์ (แต่ก่อนหน้านี้เกิดอะไรขึ้นนั้น ตอบไม่ได้)
    — update: 10 ต.ค. 2549 มีการย้ายพื้นที่เกิดขึ้นจริง เนื่องจากก่อนหน้านี้มีการบล็อก IP ของม.เที่ยงคืน ซึ่ง IP เดียวกันนี้มีอีกหลายเว็บไซต์ใช้งานร่วมกัน และถูกบล็อกไปด้วย ทางบริษัทโฮสติ้งจึงจัดการย้ายพื้นที่เว็บไซต์ของม.เที่ยงคืนออกไปที่อื่นเสีย ดูข่าว (ย่อหน้า 3)
  • ส่วนกรณีเว็บ Tor ([หลอกว่า]มีปัญหาทางเทคนิค ไม่พบไฟล์ favicon.ico) ทำให้ผมตระหนักว่า อย่าเชื่อในสิ่งที่เห็น
