[TIGER API](http://www.tigerapi.org/) is a library which allows Java programmers to easily access the structure of any corpus given as a [TIGER-XML](http://www.ims.uni-stuttgart.de/projekte/TIGER/TIGERSearch/doc/html/TigerXML.html) file.

[oeze](http://www.coli.uni-saarland.de/~oeze/), one of the authors of TIGER API, has [leave a message](http://bact.blogspot.com/2004/06/penn-treebank-in-xml-format.html) to us today:

> BTW, Tiger API has moved. This is the new URL: [TIGER API](http://www.tigerapi.org/).
>
> We have also included a section describing [how to access corpora encoded in Penn Treebank format and other formats](http://www.tigerapi.org/other.php).

Thanks, oeze ! 🙂
