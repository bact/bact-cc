[H2](http://www.h2database.com/), a free SQL database engine, by the developer of [Hypersonic SQL](http://hsql.sourceforge.net/).

[Benchmarks](http://www.h2database.com/html/frame.html) (by H2) show it outperforms popular opensource db engines (embedded and client-server), like HSQLDB, Derby, MySQL and PostgreSQL, in many areas.

H2 is free, comes with source code, and you can freely distribute it (but it is NOT open source, yet).

H2 works well with [SQuirreL SQL Client](http://squirrelsql.org/), an open source (LGPL) graphical client for JDBC compliant database. It is written in Java, thus platform-independent.
