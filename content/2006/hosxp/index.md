[HOSxP](http://en.wikipedia.org/wiki/HOSxP) ([ไทย](http://th.wikipedia.org/wiki/HOSxP)), emerged from a one-man-show project (the developer is a pharmacist by training), with NO public funding, now on a real use on over 70 hospitals across Thailand. Server runs on Linux or Windows, with client on Windows. Free as in speech and beer (GPL), the source code is [on SourceForge](http://sourceforge.net/projects/hosxp).
