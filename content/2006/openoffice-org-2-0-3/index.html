โอเพนออฟฟิศ.อ็อก 2.0.3 ออกแล้ว

  • ประสิทธิภาพ – (เขาอ้างว่า) เร็วขึ้น
  • ความมั่นคง – แก้ช่องโหว่ 3 จุด
  • ไฟล์ MS Office – แปลงไปกลับได้ดีขึ้น
  • Mac OS X – รองรับ Intel MACs, Fondu integration สำหรับแปลงฟอนต์ TrueType, OpenType และฟอนต์จากยูนิกซ์
  • CSV – ปรับปรุงหลายจุด เช่น สามารถอ่านไฟล์แบบ UTF-8 ได้แล้ว
  • PDF – เพิ่มออพชั่นในการ export
  • Online update – มีเมนูสำหรับดูว่ามีรุ่นใหม่ออกมารึยัง ถ้ามีแล้วก็จะเปิดเว็บเพจขึ้นมาให้ดาวน์โหลด (ยังต้องกดโหลด/ติดตั้งเอง)
  • UI – ปรับปรุงหน้าตา, พฤติกรรมหลายจุด รวมทั้งข้อความ เพื่อให้ใช้และเข้าใจง่ายขึ้น
  • ภาษาไทย – มี child workspace สองอันถูกรวมเข้าไปแล้ว คือ sb52 (Fix that impacts Thai) และ tl19 (เกี่ยวกับการตรวจสอบลำดับการป้อนตัวอักษร Issues about Thai input sequence checking.)

สรุปว่า ใครใช้อยู่ ก็ดาวน์โหลดตัวใหม่มาได้เลยครับ 🙂 โดยเฉพาะคนที่ใช้บน Mac OS X และคนที่ใช้ภาษาไทย
