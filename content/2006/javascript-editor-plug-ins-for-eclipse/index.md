JavaScript editor plug-ins for Eclipse

- [JSEclipse](http://www.interaktonline.com/Products/Eclipse/JSEclipse/) (freeware)
- [JSEditor](http://jseditor.sourceforge.net/) (open souce, CPL)
- [myJSEditor](http://eclipse.moelleryoung.com/jseditor/) (open source, GPL)
- [MyEclipse JavaScript Editor](http://www.myeclipseide.com/ContentExpress-display-ceid-58.html) (commercial, not free)

แถม: [HTML Tidy Eclipse Plug-in](http://eclipsetidy.sourceforge.net/) (ทำความสะอาดโค้ด HTML, XHTML)

ป.ล. อยากใช้ [NetBeans](http://www.netbeans.org/) ใจจะขาด แต่ทำไมปลั๊กอิน (ฟรี ๆ) ที่อยากได้มันไม่ค่อยมีฟะ !
