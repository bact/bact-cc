[Lingua::EN::Readability](http://www.pressure.to/ruby/) is a Ruby module which calculates statistics on English text.

- counts words, sentences and syllables
- finds sentences’ breaks
- calculates [readability measures](http://en.wikipedia.org/wiki/Readability). e.g. [Fog Index](http://en.wikipedia.org/wiki/Gunning-Fog_Index), [Flesch-Kincaid level](http://en.wikipedia.org/wiki/Flesch-Kincaid_Readability_Test)
