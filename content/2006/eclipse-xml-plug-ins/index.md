ปลั๊กอินของ Eclipse กันอีกแล้ว เยอะจริง ๆ – – (T-T)

- [EclipseXSLT](http://eclipsexslt.sourceforge.net/) for XML, XSLT and XPath development
- [Relaxer/Eclipse](http://www.relaxer.org/eclipse/) for RELAX NG schema authoring
- [Eclipse Web Tools Platform (WTP)](http://www.eclipse.org/webtools/)
- [more XML-related plug-ins](http://eclipse-plugins.2y.net/eclipse/plugins.jsp?category=XML&pager.offset=0&firstItem=1)

ผมลงตัวแรกกะตัว WTP ไม่ได้อ่ะ โห dependency ยุ่บยั่บ ตัวแรก (EclipseXSLT) นั่นจะเอา WTP ส่วน WTP ก็จะเอา JEM, JEM ก็บอกจะเอา RCP (คือไรมั่งฟะ – -) … ไม่เอาล่ะ เลิก
