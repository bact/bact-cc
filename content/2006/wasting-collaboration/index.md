[WASTE](http://waste.sourceforge.net/) is an anonymous, secure, and encryped collaboration tool which allows users to both share ideas through the chat interface and share data through the download system. WASTE is RSA secured, and has been hearalded as the most secure P2P connection protocol currently in development.

Not so related, read about [Mesh network](http://en.wikipedia.org/wiki/Mesh_networking) research [at Microsoft Labs](http://research.microsoft.com/mesh/).
