ต่อเนื่องจากบล็อกเรื่อง [สิทธิชัย หยุ่น สัมภาษณ์ นายกอภิสิทธิ์ ผ่านทวิตเตอร์](http://bact.blogspot.com/2009/09/suthichai-pmabhisit.html "@suthichai และ @PM_Abhisit แสดงสด-ออนไลน์-เพื่อออฟไลน์"), มีคำถามมา ผมตอบ :

[@Oakyman](http://twitter.com/Oakyman/status/3959056141): “@nopparat @bact คนเพิ่งหัดใช้ twitter จะใช้ @ เพื่อ reply เป็นเหรอ? บนหน้าเว็บมันมีปุ่ม update อยู่ปุ่มเดียวนิ เห็นใจ @PM_Abhisit หน่อยเถอะ”

[@bact](http://twitter.com/bact/status/3959139012): “@Oakyman ถ้าพูดแบบนั้น คือ @suthichai นี่ไม่น่าเห็นใจใช่ป่ะ”

[@Oakyman](http://twitter.com/Oakyman/status/3959334097): “@bact เห็นด่าแต่ทั่นนายกฯ หนะ อย่างน้อยคุณ @suthichai เค้ายัง rt เป็นนะ”

[@bact](http://twitter.com/bact/status/3974924196): “@Oakyman ไม่ได้ด่าใครนะ เรายกคำพูดต่างๆ ที่เห็นว่า mode สื่อสารของ @PM_Abhisit และ @suthichai ยังเป็น mode “คุยกันแค่สองคน” มาน่ะ”

[@bact](http://twitter.com/bact/status/3974937218): “@Oakyman แม้แต่การ rt ของ @suthichai ในวันสัมภาษณ์ ก็เป็นการ rt ให้ @PM_Abhisit อ่าน ในฐานะคำถามต่อ @PM_Abhisit”

[@bact](http://twitter.com/bact/status/3974982183): “@Oakyman ใช้ @reply หรือไม่ ไม่ใช่สาระสำหรับเรา / สาระคือ mode สื่อสารของ2คนนั้น มีแค่2คนคุยกัน ไม่สนใจคนอื่น (ดังนั้น @ จึงไม่จำเป็น)”

[@bact:](http://twitter.com/bact/status/3975340109): “@Oakyman ยิ่งถ้าอ่านจาก [กลุ่มคนดูเป้าหมาย คือ TV](http://twitter.com/PM_Abhisit/status/3819925216 "@PM_Abhisit: 'ช่อง9จบแล้วครับ ให้ผมเข้านอนได้รึยังครับ'") ซึ่งเข้ามาร่วมวงโต้ตอบอะไรไม่ได้อยู่แล้ว ก็ยิ่งยืนยันสมมติฐาน mode สื่อสารที่มีแค่2คน”

[@bact](http://twitter.com/bact/status/3975014865): “@Oakyman คำถาม: ถ้า mode สื่อสารเป็นแบบนั้น ไม่ต้องการการมีส่วนร่วม จะใช้twitterทำไม – คำตอบที่นึกออก: PR ความเป็น new media ของท้ัง2คน”

[@bact](http://twitter.com/bact/status/3975040896): “@Oakyman ซึ่งมันก็โอเคนะ จะใช้ยังไงก็ใช้ไปเถอะ มันเป็นพื้นที่เปิด เราก็แค่พยายามอธิบายว่า เขาใช้แบบนี้ เท่านั้นเองน่ะ”
