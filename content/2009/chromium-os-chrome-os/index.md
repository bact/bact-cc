[Chromium OS มาแล้น](http://googleblog.blogspot.com/2009/11/releasing-chromium-os-open-source.html) [@kengggg](http://twitter.com/kengggg) กำลังหาทางยัดฟอนต์ไทยใส่ลงไปอยู่ ใครมีฟอนต์อะไรน่าใช้ + สัญญาอนุญาตประมาณ BSD หรือโอเพนซอร์สอื่น ๆ ลองบอกเขาดูครับ

ดูหน้าตาแล้ว ก็น่าจะเหมาะกะเน็ตบุ๊กดีนะ

ถ้าจะ build เอง ไปเอาซอร์สที่ [chromium.org](http://www.chromium.org/chromium-os) ต้องมี Linux ถึงจะ build ได้

ถ้าขี้เกียจ ไปเอา vm image ได้ที่ [gdgt.com](http://gdgt.com/google/chrome-os/download/) (ต้องลงทะเบียน-ฟรี ใช้ Facebook Connect ได้) ได้ image มาแล้ว รันกะ [VMWare](http://www.vmware.com/products/) หรือ [VirtualBox](http://www.virtualbox.org/) (ตัวหลังนี้ฟรี-โอเพนซอร์ส)

โหลดมาเสร็จ ก็ติดตั้ง ใครไม่ถนัด VirtualBox [TechCrunch โชว์วิธีติดตั้ง แบบทีละขั้น](http://www.techcrunch.com/2009/11/19/guide-install-google-chrome-os/)
