[SketchBoard™](http://sketchboard.sourceforge.net/) is a sketch oriented CAD software. It is a tool for helping Architects and Designers to develope their design by sketching. This software would help designing architecture, interior and industrial design.

The project has developed by [Pojchara JATUPOJ](http://pojchara.mangobyte.com) of the [Computer Aided Design program](http://cad.architecture.arch.chula.ac.th/), Department of Architectural, Faculty of Architecture, Chulalongkorn University (ภาควิชาสถาปัตยกรรมศาสตร์, สาขาวิชา คอมพิวเตอร์ในงานออกแบบสถาปัตยกรรม, คณะสถาปัตยกรรมศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย)

The program is based on OpenGL and Qt libraries. It runs on Windows. Source code also available.
