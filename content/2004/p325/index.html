เมื่อวานว่าไปถึงตัว Livemark
ลองใช้งานกับ /. แล้ว ก็ใช้งานได้ดี

วันนี้ได้เจอของใหม่อีก 2 อัน
คือการปรับปรุงคำสั่ง Find กับการแสดงผล address bar

หลังจากเลือกคำสั่ง Find (Edit -> Find in this page..) ตามปกติแล้ว
แทนที่จะได้ pop-up window เหมือนที่แล้วๆ มา
เราจะได้แถบค้นหาตรงด้านล่างของหน้าแทน
การใช้งานเหมือนเดิม ก็พิมพ์คำที่จะหาลงไป

ในภาพจะเห็นว่า ปุ่ม “Highlight” ถูกเลือกไว้,
แบบนี้ Firefox ก็จะเน้นข้อความที่เราหาอยู่ทั้งหมดให้ด้วย

สะดวกดี ไม่ต้องลง plug-in อะไรเพิ่มเติม (เช่น Google toolbar ใน IE)

ส่วนอันนี้ก็ ‘ฟังก์ชั่น’ ใหม่,
ถ้าเข้าเวบไหนที่มันเข้ารหัสข้อมูล (https://)
ตรงช่อง address bar จะเปลี่ยนเป็นสีเหลือง
ทำให้เราสังเกตได้ง่ายขึ้น
(ไม่ต้องเหลือบลงไปมองแม่กุญแจด้านล่าง หรือสังเกตตัว s ด้านหลัง http)

(จริงๆ มันเหลืองกว่านี้นะ นี่ใช้ web palette สีมันเลยไม่ค่อยต่างกันมาก)

อันนี้แบบปกติ (ไม่ได้เข้ารหัส, http://) ก็เป็นสีขาวธรรมดา

หามาเล่นกันได้จาก Firefox nightly builds
