MSN เปิดตัวระบบค้นหาตัวใหม่ มาแนว minimalist แบบเดียวกับที่ทำให้ Google ประสบความสำเร็จมาแล้ว
แถมฟีเจอร์ต่อฟีเจอร์ ดูคร่าวๆ แล้ว มีไม่น้อยหน้ากัน
อย่างลิงก์ไปหาข่าวที่เกี่ยวข้องที่ Google มี MSN ก็มี
ส่วนที่ MS หวังทำเงินไว้เต็มที่ ก็คงที่โฆษณานี่แหละ ลักษณะเหมือน Google เป๊ะ

ที่น่าสนใจคือตัว MSN น่ะ มีเนื้อหาในมือเยอะแยะ
ถ้าเอาตรงนั้นมาร่วมเล่นด้วย ก็ท่าจะ search ได้มันน่าดู
เอาแค่ Encarta ก็แย่แล้ว เนื้อหาตั้งไม่รู้เท่าไหร่
แถม annotation ในนั้นเพียบ (ร่วมพัฒนาโดย NLP Group, Microsoft Research) ถ้าจะเอาจริงๆ หาได้ตรงแน่ๆ
คนส่วนใหญ่เค้าก็อยากได้ answer เลยทั้งนั้นแหละ link น่ะไม่อยากได้หรอก
ปีนี้ MS ส่งระบบ Question Answering System ของตัวเองร่วมใน TREC QA track ด้วย

เหมือนๆ กับที่ Amazon ก็อาศัยจุดแข็งของตัวเอง ที่มีหนังสือในรูปแบบอิเลกทรอนิกส์ตั้งไม่รู้เท่าไหร่
พอมาทำเสริช์เอนจิ้นของตัวเอง (A9) ก็มีฟีเจอร์ค้นหาในหนังสือได้ด้วย ไปกันใหญ่ เจ๋งจริงๆ
whatwewant: A9

ตัว Google ไม่ได้มีเนื้อหาอะไรของตัวเองแบบนั้น
ไม่รู้ว่าการเสนอบริการ Gmail กับ Google Groups (ทั้งแบบดั้งเดิม คือ newsgroups และแบบ mailing list ทำนอง yahoogroups) รวมถึง Blogger.com นี่ด้วย นี่จะเป็นการขยายเนื้อหาของตัวเองรึเปล่า
ประมาณว่า information is in the conversation

หรือจะ p2p search .. ไปค้นไฟล์ในเครื่องคนอื่นด้วย?
