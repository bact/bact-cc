--- title: "Microsoft buys Lookout to boost search" date: "2004-07-16T18:41:00+07:00" lastmod: "2004-07-16T18:41:00+07:00" type: "post" url: "/2004/microsoft-buys-lookout-to-boost-search/" description: "หลังจากเพิ่งเปิดตัว MSN Search ตัวใหม่ไปไม่นาน ไมโครซอฟต์ก็ไปซื้อบริษัท Lookout Software ซึ่งทำซอฟต์แวร์ค้นหาข้อความในโปรแกรม Outlook คาดว่านี่เป็นการเสริมความสามารถของบริการการค้นหาของ MSN Search และความสามารถต่อไปที่จะเพิ่มเข้ามา คือบริการค้นหาไฟล์ในเครื่องของผู้ใช้เอง (เครื่องที่ใช้ Windows นะ)" tag: ["microsoft"] lang: "th" wpid: 288 ---

หลังจากเพิ่งเปิดตัว MSN Search ตัวใหม่ไปไม่นาน
ไมโครซอฟต์ก็ไปซื้อบริษัท Lookout Software ซึ่งทำซอฟต์แวร์ค้นหาข้อความในโปรแกรม Outlook

คาดว่านี่เป็นการเสริมความสามารถของบริการการค้นหาของ MSN Search
และความสามารถต่อไปที่จะเพิ่มเข้ามา คือบริการค้นหาไฟล์ในเครื่องของผู้ใช้เอง (เครื่องที่ใช้ Windows นะ)
