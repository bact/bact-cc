Release Notes

จัดกลุ่ม Options (settings) ใหม่
หน้าตาโดยรวมดีขึ้น ปุ่มอะไรต่างๆ เนี๊ยบกว่าเดิม เช่นปุ่มปิด tab
(สำหรับบน Windows ก็ไม่มีอะไรมาก แต่ถ้าใช้ GTK+ จะเห็นว่าปุ่มมันดูเหมือน native GTK+ มากขึ้น)
ไอคอนที่แสดงว่ากำลังโหลดหน้าอยู่ ก็ดูโปรมากขึ้น (ใช้แบบเดียวกับ Thunderbird)
โดยใช้รูปแบบเดียวกัน ทั้งตรง tab และตรงมุมขวาบน

อะไรๆ ก็ดูดีไปหมด
ยกเว้น ไอคอนตรงทูลบาร์ back, forward, reload .. เห่ยมาก โดยเฉพาะ home เห่ยสุดบรรยาย
ระยะห่างบนล่างของไอคอนตรงทูลบาร์ ก็ดูห่างๆ ไปหน่อย

สรุปว่า ข้างในดูเหมือนดีขึ้น
แต่ข้างนอกนี่ … แย่ลงนิดๆ นะ

[โพสต์ด้วย Firefox 0.9]
