[Blastwave](http://blastwave.org/) is a collective effort to create a set of binary packages of free software, that can be automatically installed to a [Solaris](http://www.sun.com/solaris/) computer (sparc or x86 based) over the network.”

To install any package, just use [pkg-get](http://www.blastwave.org/pkg-get.php) script (pretty much like the famous apt-get).

For example, to install an Apache web server, just:

    # pkg-get install apache
