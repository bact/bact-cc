ไม่รู้ว่ามันไปอยู่ที่เวบนั้น (WinSite.com) ได้ยังไง

เป็นโปรแกรมที่เขียนไว้เล่นๆ เมื่อ… 10 ปีที่แล้ว? ถึงรึเปล่า?
จำได้ว่าต้องสมัยมัธยมนี่แหละ

สมัยนั้นเขียนปาสคาลใหม่ๆ ก็เขียนเล่นไปเรื่อย
พอดีช่วงนั้นเปิด bbs ด้วย (ชื่อ Smile Site)
ก็เลยรู้จักคนโน้นคนนี้เพิ่มขึ้น มีของให้เล่นเยอะขึ้น มันก็หนุกๆ ดี

มีตั้งกลุ่มกันด้วยนะ [SDG] ย่อมาจาก Siam Developer Gang
หลักๆ ก็มีผมกะ นาย แมนรัตน์ ชอบชื่น
คนนี้เก่งมาก เขียนปาสคาลได้สุดยอด แมนรัตน์ก็เปิด bbs เหมือนกัน ชื่อ ZeroNET
ที่เจ๋งคือ เค้าเขียนโปรแกรมควบคุม bbs เอง
(สมัยนั้นจำไม่ค่อยได้แล้ว ว่ามีโปรแกรมควบคุม bbs ที่ดังๆ อะไรบ้าง แต่ที่แน่ๆ มีอยู่ตัวนึงชื่อ WildCat ฟังก์ชั่นเพียบ)

จำได้ว่าโปรแกรมที่เขียน นอกจากไอ้ตัวแก้(บิตแมบ)ฟอนต์นี่แล้ว
ก็ยังมีโปรแกรมรายชื่อบีบีเอสในเมืองไทย (ใช้เป็นโปรแกรมสมุดโทรศัพท์ก็ได้)
แล้วก็มีโปรแกรมฐานข้อมูลตัวย่อ (อันนี้เขียนด้วย Clipper)
แล้วก็โปรแกรมอ่าน text file แต่เป็น text file ที่มี tag สีต่างๆ
ถ้าอ่านด้วยโปรแกรมของมัน ก็จะแสดงเป็นสีในจอให้ดูได้

นึกๆ ไปแล้วก็สนุกดี

แต่ให้มาเขียนตอนนี้ ท่าทางจะทำไม่ได้แล้ว -_-”

เสียดายพวกซอร์สโค้ดด้วย หายไปหมดแล้ว
เครื่องมันมีปัญหา ยกไปให้เค้าซ่อม
ที่ร้านเล่น ghost ล้างฮาร์ดดิกส์เกลี้ยงเลย
จำได้ว่าโกรธมากวันนั้น ทั้งโกรธทั้งเศร้าโคตรๆ
เพราะว่าฮาร์ดดิสก์อันนั้น เก็บงานทั้งหมดที่เคยทำมาตั้งแต่เริ่มเล่นคอม
รวมทั้งข้อมูลต่างๆ ที่หาไว้เตรียมทำซีเนียร์โปรเจ็คด้วย
ไหนจะ mp3 ที่หายากๆ อีก
(จนป่านนี้บางเพลงยังใหม่ไม่เจอก็มี เทปหรือซีดีก็หาซื้อไม่ได้)
เจ็บใจโคตร ร้านมันก็ไม่รับผิดชอบอะไรเลย

ตัวแมนรัตน์นี่ ไม่นานนี้ ก็ยังมีผลงานออกมาอยู่
SiamSurfer++ เป็นเวบเบราเซอร์แบบไทยๆ

จะบอกว่า ตั้งแต่สมัยโน้น ที่เล่น bbs กัน
ไม่เคยเจอตัวจริงกันเลย

แต่เมื่อประมาณสองปีที่แล้ว ที่งานสัมมนาอะไรซักอย่างที่ ไบเทค บางนา เกี่ยวกะโอเพนซอร์สนี่แหละ
พี่ที่บริษัท (พี่สุธรรม) กับ พี่นุสรณ์ ไปกัน ในนามทีมปลาดาวออฟฟิศ เราก็ติดไปด้วย
อ.วิรัช ไปเป็นผู้ดำเนินรายการอยู่เซสชั่นนึง ตัวเราก็ไปฟังด้วย (ตอนนั้น อ.วิรัช ยังอยู่เนคเทค)

ตอนจบเซสชั่น ก็มีคนเดินมาทัก .. แนะนำตัว
อ้าว นี่มันแมนรัตน์นี่นา แบบ งงเลย
รู้สึกตอนนั้นทำงานอยู่ไอเอสพีนึง (Pacific Internet?)
แต่ตอนนี้ล่าสุดได้ข่าวว่าไปทำ SI (system integrator) แล้ว ซักที่

ของบางอย่างเราก็ไม่รู้ว่ามันเริ่มตรงไหนเนอะ
แล้วก็ไม่รู้มันจะไปจบตรงไหนด้วย
