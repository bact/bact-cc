มีเบราเซอร์ที่ทำตามมาตรฐานแล้ว ก็ต้องมีเว็บที่ทำตามมาตรฐานด้วย — ไม่งั้นก็ไม่มีใครใช้

Standard-compliant web browser (like [Firefox](http://www.mozilla.org/products/firefox/), [Konqueror](http://www.konqueror.org/), [Mozilla Suite](http://www.mozilla.org/products/mozilla1.x/), [Netscape](http://channels.netscape.com/ns/browsers/), [Opera](http://www.opera.com/), and [Safari](http://www.apple.com/safari/)) goes best with standard-compliant website.

Promoting standard-compliant browser alone is not enough. To gaining more momentum, and also general web audiences [“peace of mind”](http://browsehappy.com/ "Browse Happy"), we have to further promoting [the web standards](http://www.webstandards.org/).

The more webs comply to the standards, the less trouble the user will faced with standard-compliant browsers — the easier for users to switch.

For developers, here’re few good books on designing website to comply with web standards: [Eric Meyer on CSS](http://www.ericmeyeroncss.com/), [Designing with Web Standards](http://www.zeldman.com/dwws/), and [HTML & XHTML: The Definitive Guide](http://www.oreilly.com/catalog/html5/index.html). Also please refers to the standard bodies like [W3C](http://www.w3c.org/ "World Wide Web Consortium"), [OASIS](http://www.oasis-open.org/ "OASIS Open"), etc.

WaSP: “[The Web Standards Project](http://www.webstandards.org/) is a grassroots coalition fighting for [standards](http://www.webstandards.org/about/) that ensure simple, affordable access to web technologies for all.”

Btw, the standard encoding for Thai characters on the Internet (e.g. for webpages) is [TIS-620](http://www.nectec.or.th/it-standards/std620/std620.htm). Read more about it, [here](http://linux.thai.net/~ott/docs/tis-620.html). Or if your page is going to be multilingual, just use UTF-8.

charset ของตัวอักษรไทย คือ TIS-620 เขียนเว็บไทยทุกครั้ง อย่าลืม [ตั้งให้ถูกต้อง](http://linux.thai.net/~ott/docs/tis-620.html)

Use [W3C Markup Validation Service](http://validator.w3.org/) to check if your web page is conform to web standards or not. ตรวจสอบว่าหน้าเว็บของคุณ เขียนขึ้นมาตรงตามมาตรฐานรึเปล่า

**Update:** แก้ทุก “complaint” เป็น “compliant”, ขอบคุณพี่เทพครับ.
