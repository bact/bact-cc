เห็นด้วยมากๆ ว่าแต่ละดิสโทรมีซอฟต์แวร์ ‘เยอะเกินไป’  
ไม่เห็นจำเป็นต้องลงมาให้หมดทุกอย่าง

พูดถึงว่า ถ้าอินเตอร์เนตเมืองไทยมันเร็วๆ กว่านี้  
ไปแบบ install on demand ก็น่าจะเวิร์ก  
หรือว่าจะเรียกหาจากแผ่น แบบ MS Office ก็ได้  
(คือลงไปแต่ ‘stub’ เอาไว้ให้เรียกใช้โปรแกรมได้ แต่ยังไม่ลงตัวโปรแกรมจริงๆ  
รอจนกว่าผู้ใช้จะเรียกใช้ส่วนนั้นครั้งแรกเมื่อไหร่ ก็จะเรียกหาแผ่นซีดี เพื่อติดตั้งตัวโปรแกรมจริงๆ)

ไอ้อย่าง apt หรือ emerge นี่มันก็ดี  
แต่ว่ามันก็อาจจะซับซ้อนเกินไปอยู่ดี

อย่างเกิดว่า เรามีไอคอนของ OpenOffice.org อยู่ในเมนู program มาให้ตอนติดตั้งเลย  
แต่ว่าตัว OO.o จริงๆ เรายังไม่ลงให้  
รอเมื่อไหร่ผู้ใช้เรียกใช้ ก็ค่อยไป apt ไป emerge ฯลฯ มาลงให้  
(อืม.. ท่าจะคอมไพล์นานนะ :P)  
ถ้าเรียกใช้แค่ Writer ก็ลงให้แค่ Writer พวก Calc ไรงี้ไม่ต้องลงให้  
(รอจนกว่าเค้าจะเรียกใช้ Calc ค่อยลงให้)

แต่กรณีพวกซอฟต์แวร์ที่มัน tightly-integrated กัน  
อย่างพวกชุดโปรแกรมสำนักงาน (office suite) นี่  
ก็อาจจะต้องอาศัยความร่วมมือจากแต่ละโปรแกรมเหมือนกัน  
(คือถ้า Writer ไปเรียกใช้ Calc ก็ต้องไปแจ้งให้ตัวจัดการ package ทราบด้วย  
เพื่อที่ตัวจัดการ package จะได้ไปเอามาลงให้)

ถ้าทำแบบนี้ได้ทั้งหมด  
ก็จะลงแค่เท่าที่ใช้จริงๆ
