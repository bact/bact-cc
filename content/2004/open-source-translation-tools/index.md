กันลืม

เห็น [XLIFF](http://www.oasis-open.org/committees/tc_home.php?wg_abbrev=xliff) มานานแล้ว แต่ก็อย่างที่ในบล็อกนั้นว่า มันยังไม่มี open source implementation เลย.  
นอกจากตัวนี้แล้วก็ยังมีมาตรฐานอื่นๆ ที่เกี่ยวข้องอีก เช่นมาตรฐานการเก็บคำศัพท์ (terminology) หรือ translation memory เพื่อที่จะได้เอามารีไซเคลใช้ได้อีก (จากโปรเจกต์นึงไปอีกโปรเจกต์นึง) ตัวที่เด่นๆ ก็คือ [TMX](http://www.lisa.org/tmx/).

มาตรฐานพวกนี้ ซอฟต์แวร์ [CAT](http://en.wikipedia.org/wiki/Computer-assisted_translation) (computer-assisted translation) อย่าง [TRADOS](http://en.wikipedia.org/wiki/SDL_Trados) สนับสนุนหมดทุกตัว  
แต่ก็ต้องเสียตังค์ซื้อน่ะ ไม่ใช่ถูก
