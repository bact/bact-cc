Following its cousin [Thai langpack](http://bact.blogspot.com/2008/04/early-thai-minefield.html), **Firefox 3.0pre localized build for Thai** is [out now](http://code.google.com/p/thai-l10n/downloads/list)! Thanks all [House 2.0](http://www.blognone.com/node/7507) and [Thai L10n](http://groups.google.com/group/thai-l10n/) people \[[vdo clip](http://duocore.ch7.com/ep72/) @ duocore.tv\].

ผลลัพธ์จากงานเย็นทั่วหล้ามหาสงกรานต์ [Firefox Thai L10n sprint](http://spreadsheets.google.com/pub?key=pLOZh-K4NhhoddNzHpshcVQ) @ [House 2.0](http://www.blognone.com/node/7507) \[[ดูคลิป](http://duocore.ch7.com/ep72/) ที่ duocore.tv\] มาแล้ว

**[ไฟร์ฟ็อกซ์ 3.0pre ภาษาไทย](http://code.google.com/p/thai-l10n/) (รุ่นทดสอบ)** ลองวันนี้ ทั้งบน GNU/Linux, Mac OS X และ Windows XP [ดิจิทัลดาวน์โหลด](http://code.google.com/p/thai-l10n/downloads/list) (ทุกค่าย)

งานนี้ [pittaya](http://twitter.com/pittaya) เจ้าหนุ่มพลังบิวด์ ซัดไปหลาย build 😛

ไม่ชอบใจ พบที่ผิด แจ้งที่ [หน้าร้องเรียน](http://code.google.com/p/thai-l10n/issues/list)

*updated 2008.04.18:* pittaya’s on [Firefox 3 Thai Localized Build](http://www.pittaya.com/2008/firefox-3-thai-localized-build/) เล่าแบบละเอียด ๆ
