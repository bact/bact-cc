ใช้ลีนุกซ์ เกิดจำเป็นต้องอ่านเอกสารในรูปแบบ [CHM](http://en.wikipedia.org/wiki/Microsoft_Compiled_HTML_Help) (Microsoft Compiled HTML Help) ขึ้นมาจะทำไง ?

สำหรับคนใช้ GNOME เรามี **[GnoCHM](http://gnochm.sourceforge.net/)** ครับ  
(ส่วนพลพรรค KDE ลอง **[KchmViewer](http://www.kchmviewer.net/)** ดู – เหมือนอินเทอร์เฟซในการค้นหาจะสะดวกกว่าแฮะ)

บน Ubuntu ติดตั้ง GnoCHM ง่าย ๆ :

    sudo apt-get install gnochm

หน้าตาเป็นงี้ (เปิดดู [Rails CHM Documentation](http://delynnberry.com/projects/rails-chm-documentation/))

[![CHM viewer on GNOME](https://farm3.static.flickr.com/2365/2479203201_5d41f1c83f.jpg)](http://www.flickr.com/photos/arthit/2479203201/ "CHM viewer on GNOME by arthit, on Flickr")

หรือใครสะดวกเป็น PDF กว่า เช่นจะเอาไปพิมพ์ลงกระดาษ ลอง **[chm2pdf](http://code.google.com/p/chm2pdf/)** ลงง่าย ๆ เช่นกัน :

    sudo apt-get install chm2pdf

ทุกอย่างทำได้ (บางทีก็เหนื่อยหน่อย) ด้วยซอฟต์แวร์เสรี
