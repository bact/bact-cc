**[Improving code with Eclipse plugins](http://www-128.ibm.com/developerworks/java/library/j-ap01117/index.html "@ developerWorks")** — developerWorks แนะนำ 5 ปลั๊กอิน สำหรับ Eclipse ที่จะช่วยหา “โค้ดแย่ ๆ” ให้คุณ

- (ชื่อ — ใช้สำหรับตรวจสอบ/ตรวจหา… — Plug-in update URL)
- [CheckStyle](http://checkstyle.sourceforge.net/) — มาตรฐานการเขียนโค้ด (รูปแบบ, ชื่อ ฯลฯ) — http://eclipse-cs.sourceforge.net/update/
- [Coverlipse](http://coverlipse.sourceforge.net/) — ความครอบคลุมของชุดทดสอบ — http://coverlipse.sourceforge.net/update
- [PMD](http://pmd.sourceforge.net/) — โค้ดที่อาจจะเป็นบั๊ก ที่ไม่ถูกเรียกใช้ ที่ไม่มีประสิทธิภาพ ที่ซับซ้อนเกินจำเป็น ที่เหมือนกัน (จากการลอกแปะ) — http://pmd.sourceforge.net/eclipse/
- [JDepend](http://clarkware.com/software/JDepend.html) — package dependency — http://andrei.gmxhome.de/eclipse/
- [Metrics](http://metrics.sourceforge.net/) — ความซับซ้อนของโค้ด — http://metrics.sourceforge.net/update
