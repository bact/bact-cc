**YAiTRON** is a cleaned-up version of NECTEC’s [LEXiTRON](http://lexitron.nectec.or.th/) in a *well-formed* XML format, created by [Vee Satayamas](http://www.vee-u.com/). Its tag names are [TEI](http://en.wikipedia.org/wiki/Text_Encoding_Initiative)-inspired.

- [YAiTRON wiki](http://th.lug.wikia.com/wiki/YAiTRON_(English-Thai_dictionary)) – about YAiTRON and its XML structure
- data: [data-20070709](http://www.vee-u.com/src/yaitron-data-20070709.tar.bz2) – [release notes](http://veer.exteen.com/20070709/yaitron-update)
- extracted data: [extracted-20070709](http://arthit.googlepages.com/yaitron-extracted-20070709.zip) – word list extracted from data-20070709, one part-of-speech per each file
- scripts: [scripts-20070926](http://arthit.googlepages.com/yaitron-scripts-20070926.zip) – scripts and XSLT stylesheets for YAiTRON data manipulation
  - see docs/readme.txt for usages
  - you need an [XSLT processor](http://en.wikipedia.org/wiki/XSLT_processor) to run all \*.xsl — try “[xsltproc](http://xmlsoft.org/XSLT/xsltproc2.html)” (should be already available on GNU/Linux boxes)
  - updates will be available at [KIND wiki](http://kind.siit.tu.ac.th/)
