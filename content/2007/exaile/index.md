จากที่บ่น ๆ เรื่องโปรแกรมฟังเพลงบนลีนุกซ์ ไป[ครั้งที่แล้ว](http://bact.blogspot.com/2007/05/media-players-for-ubuntu.html) ตอนนี้เราคิดว่าเจอตัวที่ถูกใจแล้วแหละ

ใช้ <span hrf="http://www.exaile.org/">Exaile</span> มาได้แล้วซักพัก ใช้ได้ดีทีเดียว เล่นเพลงที่อยู่ในไอพ็อดได้ ก๊อปเพลงไปได้ แต่ว่าไม่มีฟังก์ชั่น sync นะ มีฟังก์ชั่นที่ชอบและไม่เคยเห็นที่ไหนมาก่อน ก็คือ Dynamic Playlist เป็นการไปดูข้อมูล “เพลงแนะนำ” จาก Last.fm แล้วก็เพิ่มเพลงพวกนั้น (ถ้ามีในเครื่อง) ลงใน playlist อัตโนมัติ เข้าท่า

ไม่ช้าด้วย (เร็วกว่า Banshee แยะ) คิดว่าจะใช้ Exaile นี่แหละเป็นหลัก

ตัว Exaile นี้ ทีมพัฒนาบอกว่า ตั้งใจให้เป็น clone ของ [Amarok](http://amarok.kde.org/) (โปรแกรมฟังเพลงบน KDE) โดยใช้ GTK+ แทน Qt  
โปรแกรมเขียนด้วย Python มีโค้ดหลายส่วนเอามาจาก [Ex Falso / Quod Libet](http://www.sacredchao.net/quodlibet)

ใน Ubuntu เลือกลงจาก package manager ได้เลย สะดวกสุด ๆ
