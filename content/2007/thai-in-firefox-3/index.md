[ร่วมพัฒนาส่วนตัดคำไทยด้วย Native API](http://scratchpad.wikia.com/wiki/Firefox_Thai) ใน Firefox 3  
(ATSUI สำหรับ Mac OS X และ Uniscribe สำหรับ Windows,  
ส่วน Linux นั้นใช้ Pango ซึ่ง[พี่เทพซัดนำไปแล้ว](http://thep.blogspot.com/2007/07/mozilla-pango-break-really-checked-in.html))

ใครสนใจก็ไปดูกันได้ครับ คันไม้คันมือ ก็ลองแกะ ๆ แก้ ๆ ดูครับ  
ในนั้นมีแนะแนวไว้แล้วนิดหน่อย ไปเขียนเพิ่มเติมก็ได้ เป็นวิกิ
