[Creating a Ruby Weblog in 10 Minutes](http://www.netbeans.org/kb/60/ruby/rapid-ruby-weblog.html "tutorial") – ใช้ [NetBeans 6.0](http://netbeans.org/ "open source IDE") สร้างเว็บล็อกด้วย [Ruby on Rails](http://rubyonrails.org/ "web MVC framework for Ruby") ใน 10 นาที

[Rails 2.0 ออกแล้ว](http://weblog.rubyonrails.org/2007/12/7/rails-2-0-it-s-done) – RESTful, template engine ใหม่, API authentication over (HTTP) SSL, simple query cache, เร็วขึ้นประมาณ 50-100%, syntax ใหม่ของ migration ที่สั้นลงมาก, ฯลฯ

[Rubinius](http://rubini.us/ "Ruby VM") – VM สำหรับภาษา Ruby, ใช้สถาปัตยกรรมแนว Smalltalk-80 เขียนด้วย C – [ใช้กับ Rails ได้](http://www.slideshare.net/evanphx/rubinius-improving-the-rails-ecosystem/ "slideshare")

แถม: [Java SE 6 Update N Early Access](https://jdk6.dev.java.net/6uNea.html) – Java SE 6 ตัวใหม่ (หรือที่เคยรู้จักในชื่อ “Consumer JRE”) – ปรับปรุงการติดตั้งและอัพเดท, ลงเฉพาะเท่าที่ใช้ ลงเฉพาะ kernel ก่อน ที่เหลือค่อยโหลดตามมา, ใช้ hardware acceleration ได้, โหลดเร็วขึ้น, L&F (สกิน) ตัวใหม่ชื่อ Nimbus
