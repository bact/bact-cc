ในการย้ายมาใช้อูบุนตูลีนุกซ์ ยังเจอเรื่องขลุกขลักนิด ๆ หน่อย ๆ ให้พอหงุดหงิด/สนุก  
เช่นเรื่องการจัดการรายชื่อเพื่อน (Buddy List) ของ [Gaim](http://www.pidgin.im/ "Pidgin") ลำบากมาก ถ้าเกิดว่ามีเพื่อนในรายการเยอะ ๆ  
ไม่มีหน้าจอสำหรับจัดการรายชื่อเพื่อนโดยเฉพาะ ไม่มีคลิกขวา แล้วเลือก Move to group (เช่นที่ Windows Live Messenger มี)

และสำหรับโปรแกรมฟังเพลงแล้ว เท่าที่ลองอยู่นาน [Banshee](http://banshee-project.org/) และ [Rhythmbox](http://www.gnome.org/projects/rhythmbox/) อ่าน id3 tag ได้ห่วยกว่า Quod Libet เยอะ (ไม่รู้ว่าเกี่ยวกับ id3 tag version มั๊ย ? ส่วนใหญ่ในไลบรารีเพลงของผมจะเป็น v2.4)  
และ Banshee มักจะค้างนาน ๆ เวลารีเฟรชไลบรารีเพลง (บางทีแฮงค์ไปเลย)

[Quod Libet](http://www.sacredchao.net/quodlibet) (กับโปรแกรมพี่น้อง Ex Falso) เก่งเรื่อง id3 tag มาก แต่ดูเหมือนจะมีปัญหากับยูนิโค้ด ?? ไม่ค่อยแน่ใจเท่าไหร่ แต่ tag ที่เขียนเป็นภาษาไทยใน Quod Libet ไปเปิดโดยโปรแกรมอื่นจะเป็น ???? (ผมอาจจะเซตอะไรผิดเอง)

ก็เลยจะลอง [Songbird](http://www.songbirdnest.com/) ดู  
ความต้องการหลักคือ ต้องอ่าน id3 ภาษาไทยได้ และ sync กับไอพ็อด ได้

Songbird ไม่มีใน repository ต้องไปดาวน์โหลดมาลงเอง

หน้าบล็อกนี้ [Media Players Available for Ubuntu Linux](http://onlyubuntu.blogspot.com/2007/03/media-players-available-for-ubuntu.html)  
อธิบายวีธีการติดตั้งโปรแกรมดูหนังฟังเพลงต่าง ๆ บนอูบุนตูลีนุกซ์ จากบล็อก Only Ubuntu Linux

ทดลอง import เพลงเข้า Songbird แล้ว เฮ่อ … ชื่อเพลงยังคงเป็นชื่อไฟล์ซะเกินครึ่ง id3 tag ของเราหายไปไหนหมด ? 🙁

เอ้า เดี๋ยวลอง [Exaile](http://www.exaile.org/) อีกตัว!
