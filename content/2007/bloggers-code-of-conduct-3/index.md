CyberJournalist.net นำ [จรรยาบรรณของสมาคมผู้สื่อข่าวสหรัฐ](http://www.spj.org/ethics_code.asp "Society of Professional Journalists Code of Ethics") มาปรับ  
เป็น [จรรยาบรรณบล็อกเกอร์](http://www.cyberjournalist.net/news/000215.php "A Bloggers' Code of Ethics")

ซึ่งอันนี้จะเน้นที่ตัวเนื้อหามากกว่า[ที่ทิมเสนอ](http://bact.blogspot.com/2007/08/bloggers-code-of-conduct-2.html "Bloggers' Code of Conduct (2)") (อันนั้นจะเน้นที่ความเห็น)

เน้น 3 หลัก

**Be Honest and Fair – ซื่อตรง เท่าเทียม**  
ซื่อตรง จริงใจ ยุติธรรมและเท่าเทียม ในการเสาะหา รายงาน และตีความข้อมูล

**Minimize Harm – ก่อให้เกิดความเสียหายน้อยที่สุด**  
ปฏิบัติตัวต่อแหล่งข่าว และบุคคลในข่าว ในฐานะมนุษย์ ซึ่งสมควรได้รับความเคารพ

**Be Accountable – อธิบายได้ โปร่งใส รับผิดได้**  
ไม่ลำเอียง เปิดเผยอย่างชัดเจนเกี่ยวกับ จุดประสงค์และนโยบายของเว็บ ผลประโยชน์ทับซ้อน วาระส่วนตัว ความชื่นชอบส่วนตัว

ผมว่าก็ชัดดี
