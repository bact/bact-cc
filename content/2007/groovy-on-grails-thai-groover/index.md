Ruby มี [Ruby on Rails](http://www.rubyonrails.org/ "RoR") แล้ว ถึงตา [Groovy](http://groovy.codehaus.org/) มั่งล่ะ.. “Groovy on Grails” 😛

[Grails](http://grails.org/) เป็น webapp framework ลักษณะ [MVC](http://en.wikipedia.org/wiki/Model%E2%80%93view%E2%80%93controller "Model–View–Controller") (model-view-controller) ที่ใช้แนวคิด convention over configuration เหมือนกับ Rails

ที่น่าสนใจมาก ๆ สำหรับ Grails ก็คือ มันทำงานอยู่บนเทคโนโลยีที่ได้รับการพิสูจน์มาแล้วในงานขนาดใหญ่(ยักษ์) อย่าง [Java Servlet](http://en.wikipedia.org/wiki/Java_Servlet), [Spring](http://en.wikipedia.org/wiki/Spring_Framework_%28Java%29) และ [Hibernate](http://en.wikipedia.org/wiki/Hibernate_%28Java%29) (สำหรับ model)

และเพราะมันใช้ภาษา [Groovy](http://en.wikipedia.org/wiki/Groovy_%28programming_language%29) ซึ่งสามารถใช้ Java class/object ได้สบาย ๆ ดังนั้นเราจึงสามารถโค้ด/ไลบรารีจาวาได้ทั้งหมด (ซึ่งมันมีอยู่เยอะมาก ทั้งฟรีและไม่ฟรี)

ส่วนตัวภาษา Groovy เอง ก็กำลังอยู่ในกระบวนการทำให้เป็นมาตรฐานจาวา ([JSR 241](http://www.jcp.org/en/jsr/detail?id=241 "Java Specification Requests 241: The Groovy Programming Language"))
