[WeirdX](http://www.jcraft.com/weirdx/) นี่ เป็นโปรแกรม ที่ทำให้เราสามารถเรียกใช้โปรแกรมบน X ได้จากเว็บเบราเซอร์เลย  
เนื่องจาก WeirdX ใช้ JDK 1.1 ดังนั้นจึงไม่น่าจะมีปัญหามาก ทุกๆ เว็บเบราเซอร์น่าจะใช้ได้เหมือนกันหมด จะบน Windows, Linux, หรือ Mac OS X ก็ตามเถอะ

WeirdX มาพร้อมซอร์สโค้ดแบบ GPL. ตัวโปรแกรมพัฒนาต่อมาจาก [WiredX-Lite](http://www.jcraft.com/wiredx/) อีกที (ตัวนั้นเป็นบริการ ไม่มีโปรแกรมให้ดาวน์โหลด แต่ตัวบริการนี่ก็ใช้ฟรีนะ แต่ต้องสมัครสมาชิกก่อน — ซึ่งก็ฟรีอีกเหมือนกัน)

ฝีมือบริษัทญี่ปุ่น [JCraft](http://www.jcraft.com/) ครับ
