After a long improvement, [Pike](http://pike.ida.liu.se/) is now the first scripting language [for the Semantic Web](http://pike.ida.liu.se/projects/sweb/). It includes good support for W3C’s [RDF](http://www.w3c.org/RDF/) and [OWL](http://www.w3c.org/2001/sw/WebOnt/) standards.

[Nessie](http://steam.iaeste.at/nessie/) is Pike’s derivative, with less redundant syntax. Nessie code is parsed and turned into Pike code. — [Nessie review](http://osnews.com/story.php?news_id=10169) <span class="small">(OSNews.com)</span>.
