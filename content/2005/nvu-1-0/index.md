[W3C CSS home page](http://www.w3.org/Style/CSS/) reports: “[Disruptive Innovations](http://disruptive-innovations.com/) and [Linspire](http://www.linspire.com/) published version 1.0 of [Nvu](http://www.nvu.com/), a WYSIWYG Web site editor, based on [Gecko](http://www.mozilla.org/newlayout/) (Windows, Mac, Linux/X, Open Source).”

โปรแกรมสร้างเว็บเพจ [Nvu](http://www.nvu.com/) รุ่น 1.0 โอเพนซอร์ส โหลดไปใช้กันได้แล้ว ฟรี  
ทำนองเดียวกะ FrontPage หรือ Dreamweaver นี่แหละ (แต่อาจจะเก่งไม่เท่า ต้องลองเองแฮะ)
