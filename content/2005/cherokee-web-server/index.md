[Cherokee](http://www.0x50.org/ "Cherokee Web Server") is a flexible, [very fast](http://www.0x50.org/index.php?option=com_content&task=view&id=5&Itemid=5), lightweight Web server. It is [implemented entirely in C](http://www.0x50.org/index.php?option=com_content&task=view&id=9&Itemid=8), and has no dependencies beyond a standard C library. It is embeddable and extensible with plug-ins. It supports on-the-fly configuration by reading files or strings, **TLS/SSL** (via GNUTLS or OpenSSL), virtual hosts, authentication, cache friendly features, **PHP**, custom error management, and much more. — GPLed.
