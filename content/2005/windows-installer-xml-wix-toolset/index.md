โปรแกรมสร้างตัวติดตั้งสำหรับ Windows

โอเพนซอร์ส<u>โดยไมโครซอฟต์</u> ใช้ [Common Public License](http://www.opensource.org/licenses/cpl1.0.php) (<u>OSI รับรอง</u>)

- [Windows Installer XML (WiX) toolset](http://sourceforge.net/projects/wix/) โครงการที่ sourceforge.net
- [Introducing WiX](http://www.ondotnet.com/pub/a/dotnet/2004/04/19/wix.html) แนะนำ WiX พร้อมตัวอย่างสั้นๆ
- [WiX Tutorial](http://www.tramontana.co.hu/wix/) อันนี้สอนกันเป็นเรื่องเป็นราวเลย
- [Using WiX to create Windows Installer Packages](http://msdn.microsoft.com/chats/transcripts/windows/windows_110904a.aspx) chat log ถาม-ตอบ ปัญหาเรื่องการใช้ WiX
- Windows Installer: [documentation](http://www.microsoft.com/windows2000/en/advanced/help/default.asp?url=/windows2000/en/advanced/help/sag_WinInstall_Technology.htm?id=3991) \| [FAQ](http://www.microsoft.com/windows2000/community/centers/management/msi_faq.mspx)

สำหรับคนที่ใช้ Visual Studio 2003 (ไม่โอเพนซอร์สนะ) ก็มี extension ชื่อ *Votive* ทำให้จัดการได้เป็นเหมือน VS project ตัวนึงเลย

น่าจะเป็นอีกทางเลือกนึงได้เหมือนกัน (ถ้าอยากได้อะไรที่มันดู native หน่อย, เป็น .msi)

ตัวติดตั้ง MySQL 4.1 บน Windows รุ่นหลังๆ [ก็ใช้ WiX ทำเหมือนกัน](http://dev.mysql.com/tech-resources/articles/4.1/installer.html)
