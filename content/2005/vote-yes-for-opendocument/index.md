open source เปิดรหัสโปรแกรมว่าทำงานอย่างไรอย่างเดียวไม่พอ ต้องเปิดเผยด้วยว่าเก็บข้อมูลอย่างไร

OpenOffice.org 1.0 format –\> Open Office XML –\> [OpenDocument format](http://www.oasis-open.org/committees/tc_home.php?wg_abbrev=office)

OpenOffice.org 1.0 format นั้นเป็นรูปแบบการจัดเก็บ ที่โปรแกรม OpenOffice.org รุ่น 1.x ทั้งหลายใช้ รวมไปถึง [ปลาดาวออฟฟิศ](http://pladao.org/) [ออฟฟิศทะเล](http://opentle.org/officetle/) และ [StarOffice](http://sun.com/staroffice/) ด้วย

ต่อมา ทาง [Sun Microsystems](http://www.sun.com/) ก็ได้เสนอรูปแบบนี้ไปยัง [OASIS](http://www.oasis-open.org/) เพื่อพัฒนาเป็นมาตรฐาน โดยได้รับการสนับสนุนจากบริษัทและองค์กรอื่นๆ ในอุตสาหกรรม และเปลี่ยนชื่อเป็น Open Office XML

และเมื่อเร็วๆ นี้ รูปแบบนี้ก็ได้ถูกเสนอต่อไปยัง [ISO](http://www.iso.org/) เพื่อพิจารณาเป็นมาตรฐานสากล และเปลี่ยนชื่อเป็น **OpenDocument**

OpenDocument เป็นรูปแบบข้อมูลสำหรับการจัดเก็บเอกสารในสำนักงาน โดยมีพื้นฐานอยู่บนมาตรฐานสากลอย่าง XML และมาตรฐานอื่นๆ เช่น SVG, Dublin Core, MathML คือพยายามจะไม่สร้างอะไรใหม่ขึ้นมาถ้าไม่จำเป็น พยายามใช้ของเดิมๆ ให้มากที่สุด

สหภาพยุโรปเป็นเหมือน ‘ลูกค้า’ รายใหญ่ ที่รอดูอยู่ ว่าจะเลือกใช้รูปแบบไหนดี ระหว่าง [Office XML](http://www.microsoft.com/office/xml/) ของไมโครซอฟต์ กับ OpenDocument ซึ่งมีผู้ดูแลคือ OASIS และผู้สนับสนุนมากมายอย่าง OpenOffice.org, KOffice, Sun, IBM, HP, Novell, Adobe, Corel และอีกเพียบ

ทั้งสองรูปแบบ ต่างก็พยายามวิ่งเต้นกับคณะกรรมการของสหภาพยุโรปเป็นการใหญ่ เพื่อหวังจะให้รูปแบบของตนเป็นมาตรฐานในงานภาครัฐทั้งหมดของสหภาพยุโรป  
โดยทางอียู ก็ได้มีการพิจารณาทั้งสองรูปแบบ และให้ข้อเสนอแนะกับทั้งสองค่าย เพื่อนำไปปรับปรุงรูปแบบของตนต่อไป ก่อนจะมีการพิจารณาใหม่อีกรอบ

โดยทางสหภาพยุโรปนี่ เค้ามีคณะทำงานเรื่องนี้มานานแล้ว ชื่อโครงการก็คือ [1dok](http://www.1dok.org/) โดย 1dok นี่ก็เป็นสมาชิกของ OASIS ด้วย

นอกจากสหภาพยุโรปแล้ว ทางรัฐแมสซาชูเซตต์ในสหรัฐอเมริกา ก็มีท่าทีแข็งขันต่อเรื่องความโปร่งใสของการจัดเก็บเอกสารอิเลกทรอนิกส์ด้วย

ตอนนี้ <u>**ฉบับร่าง**</u> ของ OpenDocument 1.0 [ก็ออกมาให้สาธารณชนดูกันแล้ว](http://xml.coverpages.org/ni2005-01-04-a.html) รอรับคำแนะนำต่างๆ เพื่อไปปรับปรุง

อ่านๆ มานี่ ไม่ต้องบอกก็พอเดาได้ ว่าผมเชียร์ OpenDocument 😛

ไม่รู้ว่างานนี้ [คุณ James Clark](http://www.jclark.com/) ที่ตอนนี้อยู่ [SIPA](http://www.sipa.or.th/) จะช่วยดันเรื่องนี้กับทางภาครัฐของประเทศไทยได้รึเปล่า

รวมทั้งทาง Sun, IBM, HP, Novell ประเทศไทย จะมีพูดถึงเรื่องนี้กันบ้างมั๊ย?
