from [/.](http://developers.slashdot.org/developers/05/05/07/1254211.shtml?tid=108&tid=8):

mparaz writes “Geir Magnusson of the [Apache Software Foundation](http://apache.org/) [announced a J2SE 5 implementation project called ‘Harmony.’](http://mail-archives.apache.org/mod_mbox/incubator-general/200505.mbox/%3CCA4BEB82-3D84-457D-9531-1477DD749919@apache.org%3E) It covers the virtual machine and the class libraries, and aims to pass the Sun specification. A [FAQ](http://mail-archives.apache.org/mod_mbox/incubator-harmony-dev/200505.mbox/%3C50351021-6408-437D-949A-7AF2AD4DFD0F@apache.org%3E) is available.”

**Brilliant!**

Apache { HTTP Server <span class="small">(web server)</span> + Harmony <span class="small">(J2SE runtime)</span> + Jakarta/Geronimo <span class="small">(enterprise components)</span> + Ant/Maven/etc <span class="small">(development tools)</span> }  
.. what a complete <span class="small">(Java-ish)</span> stack! 😉

FYI, [Apache Geronimo](http://geronimo.apache.org/) is a J2EE implementation project of ASF, aims to pass Sun’s TCK for J2EE 1.4. The project got the test kit from Sun under [‘scholar license’.](http://java.sun.com/scholarship/)
