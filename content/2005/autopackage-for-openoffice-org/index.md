**[Vote](http://www.openoffice.org/issues/show_bug.cgi?id=46333 "go to OOo Issue Tracker to vote") for a better Linux installer for OpenOffice.org.**  
[Vote](http://www.openoffice.org/issues/show_bug.cgi?id=46333 "go to OOo Issue Tracker to vote") for Autopackage installer.

ถ้าอยากได้ Autopackage (ติดตั้งบน Linux ง่ายๆ) ของ OpenOffice.org ก็ช่วยโหวตนะครับ 🙂

ตอนนี้โปรแกรมอย่าง [Gaim](http://gaim.sf.net/downloads.php), [Inkscape](http://www.inkscape.org/download.php "Inkscape 0.41"), [AbiWord](http://www.abisource.com/release-notes/2.2.5.phtml "AbiWord 2.2.5 (experimental)"), [อื่นๆ](http://navi.cx/~mike/autopackage-pdb/ "Projects using Autopackage") ได้(ลอง)ใช้ autopackage กันแล้ว  
ผลตอบรับออกมาดีมาก [ส่วนใหญ่บอกว่า](http://osnews.com/story.php?news_id=10155)ทำให้การติดตั้งโปรแกรมบนลีนุกซ์ง่ายขึ้นมาก โดยเฉพาะกับผู้ใช้ทั่วๆ ไป (end-user)  
คือหน้าตาลักษณะการทำงานมันออกมาคล้ายๆ Windows เลย  
เวลาจะเอาโปรแกรมออก (uninstall) ก็มีโปรแกรมที่คล้ายๆ Add/Remove Program ของ Windows

ยังไงก็ลองๆ อ่านรายละเอียดที่ [issue \#46333](http://www.openoffice.org/issues/show_bug.cgi?id=46333) นะครับ มีลิงก์อยู่  
แล้วถ้าเกิดว่าอยากได้ ก็ช่วยโหวตด้วยนะครับ 🙂

ขอบคุณครับ
