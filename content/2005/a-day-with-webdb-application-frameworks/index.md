[Ruby on Rails](http://www.rubyonrails.org/ "Ruby, a language. Rails, a framework.") is on the highlight (อ่าน [pok’s blogger](http://pphetra.blogspot.com/) มีเรื่องนี้เยอะ พร้อมตัวอย่างจริง).

For Python, there’s [Subway](http://subway.python-hosting.com/), [Django](http://www.djangoproject.com/), and [SQLObject](http://www.sqlobject.org/). —  
For PHP, there’re [Cake](http://sputnik.pl/cake/) and [PHP on Trax](http://www.phpontrax.com/). —  
Java, [Trails](https://trails.dev.java.net/). —  
[Groovy](http://docs.codehaus.org/display/GROOVY/Home "Java-like scripting language on JVM"), [Grails](http://docs.codehaus.org/display/GROOVY/Grails). —  
.NET, [MonoRail](http://www.castleproject.org/index.php/MonoRail).

Most of them are Rails-inspired (well, Cake itself aggressively claims it’s actually a rip-off!)

นั่งเขียนเว็บบอร์ดใหม่เล่น ๆ ดีกว่า จะได้ลองหัดพวกนี้มั่ง

ยังไงก็ตาม ถ้าต้องเลือกใช้จริง ๆ คงไม่พ้นตัวที่ใช้ PHP, Python หรืออาจจะ Java.

ทำไม ? ก็เพราะ โฮสติ้งทั้งหลาย ส่วนใหญ่ที่เจอ ๆ มา มันใช้ได้แค่นี้น่ะ (PHP นี่เกือบทุกที่, Python ก็เยอะขึ้นละ Java นี่ก็เยอะ แต่แพงกว่าชาวบ้านหน่อย)

Ruby (and Rails) weakness: not very widespread in entry-level (cheap) hosting plans. <span class="small">\[[search “ruby hosting”](http://www.google.com/search?q=ruby+hosting)\]</span>

จะเป็น web app แต่ไม่ค่อยมี web hosting มันก็แย่หน่อยอ่ะนะ

update: ลอง Cake 0.9.1 แล้ว ยังมีบั๊กอยู่, Tutorial ที่มีอยู่ก็สำหรับรุ่นเก่า ใช้กับ 0.9.1 ไม่ได้. รุ่น 0.9.2 กำลังจะออก อีกไม่นาน
