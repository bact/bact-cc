“The goal of the [coyote](https://coyote.dev.java.net/) project is to develop a set of NetBeans modules to help developers write code in *dynamic languages* using the [NetBeans IDE](http://www.netbeans.org/). Initially, we are targeting the the [Groovy](http://groovy.codehaus.org/) and [Jython](http://www.jython.org/) (Python) languages, but we anticipate a common framework allowing support for more languages.”
