Soooo easy, just [only few clicks!](http://www.entropy.ch/software/macosx/php/) You download a dmg file, open it, double-click an installer, and that’s it! The http://127.0.0.1/\~yourname/ will be there ready for a PHP scripting!

Note: this is only for Mac OS X Client (the typical one you’ll found on desktops/notebooks), not for Mac OS X Server.
