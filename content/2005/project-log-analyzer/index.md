เขียนได้น่าอ่านมาก ละเอียด น่าสนใจ 🙂

**Project Log Analyzer [\#1](http://pphetra.blogspot.com/2005/03/project-log-analyzer-1.html), [\#2](http://pphetra.blogspot.com/2005/03/project-log-analyzer-1.html)**

โดยมีการใช้ [Common Digester](http://jakarta.apache.org/commons/digester/) มาช่วย parse xml file, และ [ANTLR](http://pphetra.blogspot.com/2005/02/antlr.html) ในการ parse query

ขออนุญาตสมัครเป็นแฟนบล็อก 🙂
