ตะกี้นั่งอ่าน [JavaDoc ของ RELAX NG Datatype](http://thaiopensource.com/relaxng/api/datatype/index.html) แล้วนึก ๆ ขึ้นมาว่า ถ้าเกิดเราเข้าไปแก้ไข ลงความเห็น ใน JavaDoc ได้ก็ดีสิ ทำแบบ Wiki ไปเลย

เลยค้นกูเกิ้ล [“javadoc + wiki”](http://www.google.com/search?q=javadoc+wiki) ได้หน้านี้มา:  
[RFC: JavaDoc + Wiki](http://forum.java.sun.com/thread.jspa?threadID=597794&tstart=0) มีคนถามถึงเมื่อสองเดือนที่ผ่านมานี้เอง

แล้วก็โยงไปถึง [WikiDoc](http://page.mi.fu-berlin.de/~oezbek/cgi-bin/view/Docu/WikiDoc) (ร่างแผนสำหรับ JavaDoc + Wiki), [JDocs](http://jdocs.com/) (รวม Java APIs), [KickJava](http://www.kickjava.com/) (API พร้อมตัวอย่าง), [JSourcery](http://jsourcery.com/) (ไล่ซอร์สโค้ดในแต่ละ API ได้)

เพิ่ม <span class="small">([จาก pok’s blogger](http://pphetra.blogspot.com/2005/04/search-java-examples-jexamplescom.html))</span>: [JExamples](http://jexamples.com/) (ค้นหาตัวอย่างโค้ด)

แต่ละอันก็มีคอนเซปต์น่าสนใจของตัวเอง ถ้ารวมทุกอันเข้าด้วยกันได้คงสุดยอด
