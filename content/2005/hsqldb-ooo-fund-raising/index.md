Efforts to embed an [HSQLDB](http://hsqldb.sourceforge.net/) database engine into the coming [OOo 2.0](http://download.openoffice.org/680/).

HSQLDB is a small (\<100kb) relational database engine which supports most of ANSI-92 SQL, with some enhancements. It is written in 100% Java.

More info: [HSQLDB OOo Integration](http://hsqldb.sourceforge.net/web/openoffice.html), [OOo Database Access Project](http://dba.openoffice.org/)
