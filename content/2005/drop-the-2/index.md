In the next release of Java platforms, there will be no “J2SE 6.0” or any “J2xx” whatsoever anymore.

In the JavaOne 2005 conference, Sun announced a simplified Java brand, [dropped the 2](http://java.sun.com/developer/technicalArticles/javaone2005/naming.html), and introduced a plain simple **“Java”** brand.
