[Thinlet](http://thinlet.sourceforge.net/) เป็นชุดอำนวยความสะดวกในการสร้างส่วนติดต่อผู้ใช้แบบกราฟิกตัวหนึ่ง ใช้ [XUL](http://www.mozilla.org/projects/xul/) เป็นตัวอธิบายหน้าตา (ทำให้แยก ส่วนอธิบายการทำงาน กับ ส่วนอธิบายหน้าตา ออกจากกันได้โดยง่าย) ใช้ได้กับ Java VM รุ่น 1.1 เป็นต้นไป รวมถึง VM ของไมโครซอฟต์ด้วย / โอเพนซอร์ส (LGPL)

[Thinlet](http://thinlet.sourceforge.net/) is a GUI toolkit for Java. It use [XUL](http://www.mozilla.org/projects/xul/) as its UI descriptor. Thinlet can runs on any Java VM that (backward) compatible with Java 1.1 spec (yes, including that Microsoft VM). Thinlet compressed size is 38KB, and it is LGPL licensed.

If you looking for a more light-weighted alternative to [Swing](http://java.sun.com/products/jfc/), then give it a try.

To make things easier, there’re few UI designers for Thinlet that will auto-generates you an XUL code. [ThinG](http://thing.sourceforge.net/) is a GPL one. [Theodore](http://www.carlsbadcubes.com/theodore/) has both freeware and commercial ones.

<u>Note:</u> If you need more advanced features, that may not in the current official release of Thinlet, you may try [Thinlet-Zee](http://www.zee.ch/thinlet/). It is a “patched” improved version of Thinlet (Thinlet itself doesn’t has any update for almost a year).
