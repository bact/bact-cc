Alastair Dunning posted this to the [TEI list](http://listserv.brown.edu/archives/tei-l.html) today :-

AHDS Literature, Languages and Linguistics has recently published a new  
Information Paper on XML editors.

With a large number of XML editors now available, [this Information Paper](http://ahds.ac.uk/creating/information-papers/xml-editors/) serves as an introduction to the different features XML editors can have and the extent to which these features are implemented. It also presents the result of an evaluation exercise where different user groups tried a number of the editors.

The article is based on a study by Thijs van den Broek, Benchmarking XML editors, undertaken in 2004. The evaluation includes results of the survey van den Broek undertook via the [TEI website](http://www.tei-c.org/).

[AHDS Literature, Languages and Linguistics](http://ahds.ac.uk/) is hosted by the [Oxford Text Archive](http://ota.ahds.ac.uk/).
