[Eclipse + Java-GNOME Demo](http://overholt.ca/wp/index.php?p=11) (Flash)

[สาธิต](http://overholt.ca/wp/index.php?p=11) (Flash) การเขียนโปรแกรมบน GNOME ด้วยภาษา Java, โดยใช้ไลบรารี [Java-GNOME](http://java-gnome.sourceforge.net/cgi-bin/bin/view) (เป็น binding ตัวนึง ที่ให้ภาษา Java เรียกใช้ไลบรารี GNOME และ GTK+ ได้).

IDE ในการสาธิตคือ [Eclipse](http://www.elipse.org/), ทำให้เห็นว่าการเขียนโปรแกรมบน GNOME ด้วยภาษา Java เป็นเรื่องง่ายๆ — แต่ไม่จำเป็นต้องใช้ Eclipse ก็เขียนได้นะ
