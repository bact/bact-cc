> If PDF is electronic paper, then [pdftk](http://www.accesspdf.com/pdftk/) is an electronic staple-remover, hole-punch, binder, secret-decoder-ring, and X-Ray-glasses. Pdftk is a command-line tool for doing everyday things with PDF documents.
>
> Pdftk allows you to manipulate PDF easily and freely. It does not require Acrobat, and it runs on Windows, Linux, Mac OS X, FreeBSD and Solaris.
>
> Pdftk is free software (GPL).
