a file “words” contains:

    abcde
    fghi
    jklm
    nop
    qrst
    uvw
    xyz

a file “digits” contains:

    12
    3
    45
    678
    910
    11

`paste words digits` command gives:

    abcde 12
    fghi 3
    jklm 45
    nop 678
    qrst 910
    uvw 11
    xyz
