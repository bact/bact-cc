Heard about this from [pok’s blog](http://pphetra.blogspot.com/2005/04/classifier4j.html).

[Classifier4J](http://classifier4j.sourceforge.net/) is a Java library designed to do text classification. It comes with an implementation of a [Bayesian classifier](http://en.wikipedia.org/wiki/Binary_classification), and now has some other features, including **a text summary facility**.
