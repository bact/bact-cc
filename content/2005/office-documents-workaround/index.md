สำหรับใครที่ไม่มีชุดโปรแกรม Microsoft Office แต่มีความจำเป็นต้องเปิดดูเอกสารจากโปรแกรมพวกนั้น (เอกสาร Word, สไลด์ PowerPoint, ตาราง Excel)  
ลองโปรแกรมพวกนี้ดูได้ ฟรี

- [Antiword](http://www.winfield.demon.nl/) อ่านไฟล์ Word ได้ ใช้ได้กับหลายระบบปฏิบัติการ (Windows, Linux, Mac OS, DOS, FreeBSD, etc.)
- [Word Viewer 2003](http://www.microsoft.com/downloads/details.aspx?FamilyId=95E24C87-8732-48D5-8689-AB826E7B8FDF&displaylang=en) สำหรับ Windows
- [PowerPoint Viewer 2003](http://www.microsoft.com/downloads/details.aspx?FamilyID=428d5727-43ab-4f24-90b7-a94784af71a4&displaylang=en) สำหรับ Windows
- [Excel Viewer 2003](http://www.microsoft.com/downloads/details.aspx?FamilyId=C8378BF4-996C-4569-B547-75EDBD03AAF0&displaylang=en) สำหรับ Windows
- [OpenOffice.org](http://www.openoffice.org/) อันนี้เปิดได้ทั้งไฟล์จาก Word, PowerPoint, Excel แต่อาจจะไม่เหมือนต้นฉบับ 100% แต่ดีตรงที่แก้ไขได้ ใช้ได้กับ Windows, Linux, Solaris, Mac OS X

**หมายเหตุ:**  
หลังจากอ่านได้แล้ว ให้บอกคนส่งมาด้วยว่า [ทีหลังอย่าส่งไฟล์ Word มาอีก](http://www.gnu.org/philosophy/no-word-attachments.html " We can put an end to Word attachments -- Richard Stallman")  
ไฟล์ PowerPoint ก็ด้วย อย่าส่งมา  
ให้ส่งเป็น ไฟล์ข้อความธรรมดาๆ (plain text), HTML, หรือ [PDF](http://www.adobe.com/products/acrobat/readermain.html) ซะ ขอร้อง นะ

ไฟล์ Excel นี่ไม่รู้ทำไงเหมือนกัน  
ไล่้ให้ไปใช้ [OpenOffice.org](http://th.openoffice.org/ "ภาษาไทย") ละกัน ให้ส่งมาแบบ [OpenDocument](http://www.groklaw.net/article.php?story=20050130002908154) 😛
