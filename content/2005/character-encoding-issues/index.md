[A tutorial on character code issues](http://www.cs.tut.fi/~jkorpela/chars.html) – covers many issues in character encoding

Germanic Lexicon Project:

- [An introduction to character encoding issues](http://www.ling.upenn.edu/~kurisuto/germanic/aa_character_introduction.html) – strategies for the issues
- [Character encoding](http://www.ling.upenn.edu/~kurisuto/germanic/aa_character_encoding.html) – list of characters with their coresponding code

[Multiple Representations](http://www.informit.com/articles/article.asp?p=30893&seqNum=4&rl=1) – normalization, canonical decompositions, compatibility decompositions, etc.

[Linguistic Sorting](http://www.lc.leidenuniv.nl/awcourse/oracle/server.920/a96529/ch4.htm) – how characters are sorted in an Oracle environment

[Unicode in MySQL](http://dev.mysql.com/tech-resources/articles/4.1/unicode.html) – with PHP examples

[Character Encoding and the Web](http://pclt.cis.yale.edu/pclt/encoding/) – with Thai example: “เอกชัย ศรีวิชัย”สุดทน เจอเทปผี ซี.ดี.เถื่อนแย่งตลาด สั่งลูกน้องไล่กระทืบพ่อค้าขายซี.ดี.เถื่อน พร้อมประกาศลั่น ฝากบอกเอเย่นต์ใหญ่ว่า “เอกชัย สั่งให้ทำ” !
